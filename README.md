# Messi vs Ronaldo Coin Toss - APK Build Repository

This repository contains the complete Capacitor setup and GitHub Action workflow to automatically compile the Messi vs Ronaldo Coin Toss HTML game into an Android APK.

## How to Build the APK

1. Create a new GitHub repository.
2. Push all the files from this directory to your repository's `main` or `master` branch.
3. Go to the **Actions** tab on your GitHub repository page.
4. Watch the **Build Android APK** workflow run.
5. Once complete, scroll down to the **Artifacts** section at the bottom of the workflow summary and download `Messi-vs-Ronaldo-Game-APK`.
